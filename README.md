# MIX GOLD Dashboard

لوحة تحكم MIX GOLD لإدارة المحتوى والفيديوهات ومكتبة الوسائط وإحصائيات الموقع. المشروع مبني باستخدام Next.js 14 وReact وSupabase، مع مسارات خادمية للتعامل الآمن مع الخدمات الخارجية.

## التشغيل محليًا

ثبّت الاعتماديات:

```bash
pnpm install
```

أنشئ ملف `.env.local` وضع فيه متغيرات البيئة المطلوبة للتطبيق. لا ترفع هذا الملف إلى GitHub، ولا تضع مفاتيح API أو كلمات المرور داخل الكود.

شغّل بيئة التطوير:

```bash
pnpm dev
```

شغّل الاختبارات:

```bash
pnpm test
```

أنشئ نسخة الإنتاج:

```bash
pnpm build
```

## المزايا الحالية

تتضمن اللوحة إدارة المحتوى الموحد، مطابقة صور الأغلفة من مكتبة الوسائط، إدارة روابط Vidmoly، إحصائيات الموقع مع إعادة الاتصال والمزامنة التلقائية، وإزالة مصادر YouTube القديمة من مشغلات الموقع.

## الإعدادات والأمان

اضبط مفاتيح Supabase وVidmoly وGemini وImgBB وأي تكاملات خارجية عبر متغيرات بيئة خادمية أو Secrets في منصة الاستضافة. يجب مراجعة قيم الإنتاج قبل التشغيل، وعدم مشاركة ملفات البيئة أو الرموز السرية.

هذا المستودع مخصص للكود المصدري فقط. لم يتم تنفيذ نشر تلقائي على Manus أو Vercel ضمن عملية الرفع هذه.
