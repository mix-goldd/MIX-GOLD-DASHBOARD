# التحقق من واجهة Vidmoly على الهاتف

تم فحص صفحة لوحة التحكم ضمن جلسة مستخدم مسجّل الدخول باستخدام محاكاة عرض هاتف بعرض **375px** وارتفاع **812px**.

| المعيار | النتيجة |
| --- | --- |
| عرض مساحة العرض | 375px |
| عرض مستند الصفحة | 375px |
| وجود بطاقة `Vidmoly account usage` | نعم |
| عرض بطاقة الاستخدام | 297px |
| تجاوز البطاقة لمساحة العرض | لا |
| فتح قائمة تفاصيل الحسابات | نعم |
| صفوف الحسابات الظاهرة | 5 |
| خلايا التفاصيل ذات التسميات | 30 |
| عدّاد التجدد ظاهر | نعم |
| نص العدّاد عند الاختبار | 11:23:17 |
| عرض قائمة الحسابات المفتوحة | 297px |
| تجاوز القائمة لمساحة العرض | لا |

تؤكد النتيجة أن بطاقة الاستخدام والعدّاد وقائمة حسابات Vidmoly المفتوحة لا تسبب تمريرًا أفقيًا أو قصًّا في عرض الهاتف الذي تم اختباره. وتتحول صفوف الحسابات إلى بطاقات ذات تسميات واضحة على الهاتف بدل جدول عريض.
